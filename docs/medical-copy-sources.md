확인일: 2026-09-16

## 작성 범위와 기준

- 진료 메뉴 6개 HTML의 본문 소개 6개, 질환 설명 27개, 대표 증상 27개를 보강했습니다.
- 히어로 문구, 치료 탭의 설명과 구성, 메인페이지는 이번 문안 보강 범위에서 제외했습니다.
- 의료기관과 의학회의 환자 교육 자료를 참고해 한국어로 새로 작성했습니다. 원문을 그대로 복제하거나 특정 기관의 진료 방식을 본원의 방식으로 표현하지 않았습니다.
- 각 설명은 데스크톱 본문 폭에서 약 3~4줄을 목표로 작성했습니다. 모바일에서는 화면 폭에 맞게 자연스럽게 늘어나며 내용을 잘라내지 않습니다.
- 증상만으로 진단을 확정하거나 특정 치료의 효과를 보장하지 않습니다. 아래 자료는 질환 정의와 증상 설명의 근거이며, 기존 치료 탭의 모든 적응증이나 효과를 검증한 자료는 아닙니다.
- 공개 전 담당 의료진이 용어와 문구를 검토해야 합니다. 본문은 일반적인 건강정보이며 개별 환자의 진단을 대신하지 않습니다.
