# Doctor signature font

Nanum Pen Script, provided by Google Fonts under SIL OFL 1.1 (see OFL.txt).
Local font files contain the characters 이동현 and are used only for the doctor profile signature.

- `doctor-name.woff2` — in use, paired with Italianno for the Latin "Doctor".
- `doctor-signature.ttf` — earlier TTF build of the same subset, kept for reference.
