# Doctor signature font

Nanum Pen Script, provided by Google Fonts under SIL OFL 1.1 (see OFL.txt).
Local font files contain the characters 이동현 and were used for the doctor profile signature.

Not in use. The signature moved to the more cursive Nanum Brush Script
(`fonts/nanum-brush-script/`); these builds are kept only for reference.

- `doctor-name.woff2` — woff2 subset.
- `doctor-signature.ttf` — earlier TTF build of the same subset.

Source: https://fonts.googleapis.com/css2?family=Nanum+Pen+Script&text=%EC%9D%B4%EB%8F%99%ED%98%84&display=swap
